# Design — Brand System Birth Hub 360º 2026

## Direção

A identidade do Birth Hub 360 evolui de uma simples vitrine de marca para um **Sistema Operacional de Revenue Intelligence**. A essência e paleta originais (Obsidian, Blue, Iris, Gold) são mantidas, mas a hierarquia é reestruturada para suportar um SaaS premium, funcional e orientado a dados.

A interface deve parecer uma central operacional premium de inteligência comercial ("Command Center"), e não apenas um "SaaS roxo/dourado".

## Tokens e Semântica

| Token | Papel |
|---|---|
| Obsidian | Base Estrutural |
| Midnight | Superfícies |
| Blue | Informação/Ação |
| Iris | Inteligência/IA |
| Gold | Destaque, status premium e pontos de decisão (Accent) |
| Snow | Conteúdo (Texto Principal) |

## Tipografia (Separação Marca ≠ Interface ≠ Dados)

- **Bodoni Moda:** Branding, headlines institucionais (Elegância e presença editorial).
- **Inter / Geist / Sora:** Produto, Interface, Menus (Alta legibilidade para densidade).
- **JetBrains Mono:** Dados, KPIs (Precisão estrutural, números tabulares).

## Símbolo e Logo System

- **BH360 Core:** Símbolo completo para marca e uso institucional.
- **BH360 Mark:** Símbolo reduzido para interface principal.
- **BH360 Micro:** Favicon, app icon e avatars.

## 8 Pilares (Linguagem Visual)

Cada pilar terá sua representação visual, ícone, cor funcional, estado e microanimação:
1. Hub (Núcleo)
2. Intelligence (Radar)
3. Orchestration (Fluxo)
4. Performance (Métricas)
5. Forecast (Projeção)
6. AI (Inteligência)
7. Automation (Conexão)
8. Engagement (Comunicação)

## Linguagem de IA
Fluxo padronizado para IA:
`Context → Analysis → Recommendation → Approval → Execution`

## Estados Visuais
Padronização dos estados reais: LIVE, SYNCING, PROCESSING, RECOMMENDED, ACTION REQUIRED, BLOCKED, BETA, PLANNED, NO DATA.
